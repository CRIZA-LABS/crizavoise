# CrizaVoise brand sheet

**CrizaVoise by Criza Labs**: simple invoicing for small businesses. Parent brand: Criza Labs (https://criza.dev).
Assets are in `assets/brand/` (app) and `docs/brand/` (copies). **Family sheet: `docs/brand/family.png`** (Criza Labs and CrizaVoise side by side, plus small-size tests).
Everything is generated by `tool/brand` (`npm install && npm run build`) from the Criza master logo in `D:AIProjectCRIZAlogo`.

## 1. Brand architecture: a Criza family product
CrizaVoise follows the **same identity system as Criza Labs**, not a separate style:

| Parent (Criza site) | Product (this app) |
|---|---|
| App icon: the 3D ribbon **C** on navy `#031326` | App icon: the 3D ribbon **V** on the same navy |
| Lockup **"CRIZA LABS."**: master CRIZA lettering, dot removed, "LABS" in Inter SemiBold at 0.25em tracking on the baseline, ending in a small copy of the dot | Lockup **"CRIZA VOISE."**: built by the identical rules (same proportions: word size 0.32 × height, gap 0.14 × height, dot 0.5 × word cap height) |

## 2. Name
- Write **CrizaVoise** in running text (one word, capital C and V). The logo reads **CRIZA VOISE.**, the same way the parent's logo reads CRIZA LABS.
- Lowercase `crizavoise` is only for technical IDs (package, binary, bundle ID `dev.criza.crizavoise`).
- **Credit lines:** "CrizaVoise by Criza Labs". On invoices: "Powered by CrizaVoise · criza.dev".
- Never say or imply Criza Labs created the original codebase. Third-party origins are in `THIRD_PARTY_NOTICES.md`.
- Criza Labs isn't a registered company, so don't add "Ltd", "Pvt Ltd", "LLP" or "Inc.".

## 3. The mark: "Criza V"
The **folded-ribbon "A" from the Criza logo, turned upside down**. It's rebuilt as vectors from the A's own geometry:
- flat fold cap, two parallel legs, horizontal cuts at the tips;
- the A's highlight streak on the left leg and dark crease on the right leg.

| Part | Colour | Taken from |
|---|---|---|
| Left leg | Criza red `#fd2526` → `#f61b15` → `#de0017` | the Criza "A" |
| Right leg | Criza blue `#0ad3ff` → `#00a6f5` → `#0046bc`, crease `#00297a` | the Criza "C" |
| Fold cap | `#fd533a` → magenta `#f50fa5` | the A's cap and the C's magenta seam |
| Plate | `#0a2240` → `#031326` | the Criza app-icon navy |

It reads as **V** for Voise, as a **✓ / done** shape, and as **Criza**'s own A, so the product is recognisably part of the family.

**Construction**
- **Main icon** (`mark.svg`, 1024 canvas): the V fills **70%** of the width, optically centred. Plate radius 22%, with a 7% white inner hairline so it separates on dark taskbars.
- **Small-size variant** (`mark-small.svg`, 16–47 px): same silhouette at **80%** fill. It drops the streak, crease and fold shadows, which turn to noise at that size.

### Files
| File | Use |
|---|---|
| `mark.svg` | App icon / avatar at 48 px and up |
| `mark-small.svg` | 16–47 px: favicon, title bar, tray, taskbar |
| `symbol.svg` | The V without the plate |
| `symbol-mono.svg` | One colour (`currentColor`): thermal receipts, print |
| `lockup-dark.png` | **CRIZA VOISE.** for dark backgrounds (silver letters, as on criza.dev) |
| `lockup-light.png` | **CRIZA VOISE.** for light backgrounds (letters and dot in ink `#12131a`; the C and A keep their colours) |
| `icons/icon-1024.png` | Master for store, macOS, iOS and Android icons |
| `windows/runner/resources/app_icon.ico` | 14 sizes (16, 20, 24, 30, 32, 36, 40, 48, 60, 64, 72, 80, 96, 256), following Microsoft's target-size list |

The lockups are raster because the Criza lettering exists only as PNG (see the Criza site's BRAND.md). They're built at 216 px tall, which is enough for a 3× screen at the 72 px maximum the app uses.

### Rules (inherited from Criza's BRAND.md, plus product rules)
- **Lockup minimum height 36 px.** Below that, use the mark alone.
- Keep clear space equal to the dot's height around the lockup, and equal to the leg thickness around the mark.
- Never recolour, stretch, rotate or add effects. Red is always the left leg and blue the right.
- Use the plated mark wherever the background is unknown (taskbar, store, favicon).
- Don't set "CRIZA" in a font. Always use the master lettering.

## 5. Typography
- **Bricolage Grotesque** for display text and headings (bold, slightly tight).
- **Inter** for everything else.
- Devanagari and Tibetan fall back to the bundled Noto fonts. All fonts are OFL-licensed (see `THIRD_PARTY_NOTICES.md`).

## 6. Voice
Plain, warm, short. Talk to a busy shop owner, not an accountant.
- Say "Send invoice", not "Initiate invoice dispatch".
- Lead with the action and use numbers people can check.
- No "leading", "world-class" or "cutting-edge".
- Errors say what happened and what to do next, never raw error text.

## 7. Why it's built this way (research notes, 2026-11-09)
| Practice | Source | How CrizaVoise applies it |
|---|---|---|
| Design for 16 px first; one bold silhouette; no fine detail | Logo/favicon guides (Piktochart, Zillion Designs, Inkbot) | One V silhouette; detail dropped and fill raised to 80% below 48 px |
| Simple, unambiguous, recognisable at every size; no text in the icon; don't fill the whole tile | Apple HIG (icons) | No letters in the icon; the V fills 70% of the plate |
| ICO at least 16/24/32/48/256; Windows picks the exact size or the next one up | Microsoft Learn: app icon construction | 14 sizes in the `.ico`, a pixel match at every Windows 11 scale step |
| Plated icons must handle light and dark themes themselves | Microsoft Learn | Criza navy plate plus a white hairline; tested on both taskbars (family.png) |
| Products share the parent's core visual system | Brand-architecture guides (MIT brand, Indorama brand book) | Same ribbon drawing, colours, lettering and lockup rules as Criza Labs: CRIZA LABS. ↔ CRIZA VOISE. |
| Mono and reversed versions; vector masters | Logo guides (Fiveable, Zenind) | Mono symbol, light and dark lockups; the mark is vector, and the lockup follows the parent's raster master |
